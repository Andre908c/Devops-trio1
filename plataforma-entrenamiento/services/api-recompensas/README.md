**Responsable:** Juan Camilo | **Puerto:** 3004

## Endpoints
- `GET /api/recompensas/mias` (atleta)
- `POST /api/recompensas/desbloquear`
- `GET /api/recompensas/promociones/activas` (público)
- `GET /api/recompensas/promociones` (admin)
- `POST /api/recompensas/promociones` (admin) — solo promociones, no precios base

```bash
cp .env.example .env && npm install && npm run dev
```
